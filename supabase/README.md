# Таасан уу? сервер (Supabase)

Тоглоомын үгс, оноо, анги, онооны самбар Supabase дээр хадгалагдана.
Сайт өөрөө GitHub Pages дээр хэвээр.

## Нэг удаагийн тохиргоо

1. supabase.com дээр GRIT-ийн нэрээр төсөл үүсгэнэ (Region: Singapore эсвэл Tokyo).
2. SQL Editor дээр `001_taasan_uu.sql`, дараа нь `002_words.sql`-ийг ажиллуулна.
3. Админ түлхүүр тохируулна (зөвхөн GRIT-ийн ажилтнууд мэднэ):
   ```sql
   select grit.set_admin_key('урт-нууц-түлхүүр');
   ```
4. Project Settings → API хэсгээс **Project URL** болон **publishable (anon) key**-г аваад
   `culture/taasan-uu/index.html`, `culture/teacher/index.html`, `culture/admin/index.html`
   доторх `TU_API` (url, key)-г солино. Энэ түлхүүр нийтэд ил байх зориулалттай.

## Өдөр тутмын ажил

| Хэн | Хаана | Юу хийх |
|---|---|---|
| GRIT | grit.mn/culture/admin | Сургууль, анги нэмэх → сурагчийн код, багшийн код авах |
| Багш | grit.mn/culture/teacher | Сурагчид, оноо, идэвх харах; PIN солих; CSV татах |
| Сурагч | grit.mn/culture/taasan-uu → самбар товч | Ангийн код + хоч + 4 оронтой PIN-ээр нэгдэх |

## Үг нэмэх

`002_words.sql`-ийн төгсгөлд мөр нэмээд дахин ажиллуулна. Шинэ үгийг **үргэлж төгсгөлд** нэмнэ,
эс тэгвээс өдрүүдийн дараалал өөрчлөгдөнө.

## Оноо, цол (1 улирал = 1 жил)

- Таасан өдөр: 7 − оролдлого (6 … 1). Сэжүүр −1, үсэг нээх −1, гэхдээ дор хаяж 1.
- Таагаагүй өдөр: 0 оноо, тоглосон өдөрт тооцогдоно. 7 хоногт 5+ өдөр тоглосон бол +3.
- Цол = оноо **ба** тоглосон өдөр хоёулаа хүрэх:

| Цол | Оноо | Өдөр |
|---|---|---|
| Аравтын ноён | 60 | 15 |
| Зуутын ноён | 250 | 60 |
| Мянгатын ноён | 600 | 140 |
| Түмэний ноён | 1000 | 220 |
| Хаан | 1300 | 300 |

- Анги: сурагчдын 80% нь хүрсэн цол (5+ сурагчтай анги). Сургууль доторх анги бүрийн
  цол хүрсэн огноо `grit.milestones`-д бичигдэнэ → шагнал олгоход ашиглана.
- Тоонуудыг `grit.ranks` хүснэгтэд өөрчилж болно.
