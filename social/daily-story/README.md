# Өдрийн үгийн Instagram story

Тоглоомын үгийн жагсаалтаас (`supabase/002_words.sql`) тухайн өдрийн үг, тайлбарыг автоматаар авч
1080×1920 story зураг гаргана. Өнгө нь өдөр бүр гурван хувилбараар ээлжилнэ.

```bash
cd social/daily-story
node make-story.js 2026-11-18            # «Өнөөдрийн үг» · story-18.html
node make-story.js 2026-11-18 "Өчигдрийн үг"   # маргааш өглөө нийтлэх бол
node render-story.js 18                  # story-18.jpg
```

Гарчгийг өөрчлөх бол `story-<№>.json` доторх `title`-г засаад `node buildstory.js story-<№>.json`, дараа нь `render-story.js`.

Анхаар: өдрийн үгийг тухайн өдөрт нь нийтэлбэл хариулт задарна. Орой эсвэл маргааш өглөө «Өчигдрийн үг» гэж нийтлэх нь тоглоомд илүү ээлтэй.
