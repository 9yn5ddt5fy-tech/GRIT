# Өдрийн үгийн Instagram story

Тухайн өдрийн үг, тайлбарыг Supabase-аас (`grit.word_of`) автоматаар авч
1080×1920 story зураг гаргана. Загвар нь “Таасан уу?” тоглоомын хуваалцах карттай ижил: хар дэвсгэр, хатгамал булан, GRIT морь, цагаан дөрвөлжин үсэг.

Үгийн жагсаалт нууц тул репод хадгалдаггүй. Компьютер дээрээ ажиллуулахдаа Supabase-ийн
Personal Access Token-оо `SUPABASE_TOKEN` орчны хувьсагчид өгнө.

```bash
cd social/daily-story
node make-story.js 2026-11-18            # “Өнөөдрийн үг”, story-18.jpg шууд гарна
node make-story.js 2026-11-18 "Өчигдрийн үг"   # маргааш өглөө нийтлэх бол
```

Гарчгийг өөрчлөх бол `story-<№>.json` доторх `title`-г засаад `node buildpost.js story-<№>.json`, дараа нь `render-story.js`.

Анхаар: өдрийн үгийг тухайн өдөрт нь нийтэлбэл хариулт задарна. Орой эсвэл маргааш өглөө “Өчигдрийн үг” гэж нийтлэх нь тоглоомд илүү ээлтэй.

## “Хэн бэ?” story

Тухайн өдрийн хүнийг (`grit.hb_of`) Supabase-аас авч ижил загвартай story гаргана: нэр, үе, товч түүх.

```bash
node make-hb-story.js 2026-11-26                  # “Өнөөдрийн хүн”, story-hb-26.jpg
node make-hb-story.js 2026-11-26 "Өчигдрийн хүн"  # маргааш өглөө нийтлэх бол
```

Энэ нь хариуг харуулдаг тул тоглоом дууссаны дараа (орой эсвэл маргааш өглөө) нийтлээрэй.
Тоглогчид өөрсдөө ч тоглоом дуусахад “Story зураг” товчоор хариугүй (хэдэн сэжүүрээр таасныг нь л харуулсан) зураг гаргаж хуваалцана.
